Assignment: Practical Home Exercise — UI/UX Redesign of MUST Application System

Objective
To apply UI/UX design principles and front-end development skills by replicating a key part of the MUST application system pages.

Task Brief
Study the existing MUST Student Application System interface and guidelines, then create an original, modern, replica design for the two main interfaces:

1. Login Screen
2. Account Creation / Sign-Up Screen

Requirements
1. Maintain MUST's identity.
2. Implementation must use HTML5 and CSS.
3. Design must be responsive and user-friendly.
4. Showcase good UI principles: layout, colour scheme, typography, and usability.

Deliverables
1. Two separate files: login.html and signup.html, sharing a single styles.css (or separate CSS files).

Submission
GitHub Pages link. Git commit your work containing all your HTML, CSS and documentation then host that site on GitHub.
